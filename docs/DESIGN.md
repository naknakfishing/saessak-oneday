# 디자인 계획 — 새싹 공방

작성일: 2026-10-11 · 기준 문서: [PRD.md](PRD.md) · 참고: 유튜브 채널 「낚낚 naknak」(분위기만 참고, 로고·사진은 그대로 쓰지 않는다)

## 1. 참고 채널에서 본 것

| 보이는 것 | 낚낚 채널 | 새싹 공방에 가져올 것 |
|---|---|---|
| 대표 색 | 형광 연두 배경 + 검정 | 연두는 그대로 '새싹 색'으로. 형광은 한 톤 낮춰 따뜻하게 |
| 글자 | 아주 두꺼운 둥근 고딕, 흰 글자 + 검정 테두리 | 제목·버튼에만 두꺼운 둥근 글씨. 테두리는 짙은 초록으로 얇게 |
| 썸네일 | 사람 얼굴 + 결과물(잡은 것)을 크게, 말풍선처럼 기울어진 큰 글씨 | 아이 손 + 완성 작품 사진을 크게, 짧은 문구 스티커 |
| 문장 말투 | "환장하고 달려들어요!", "터졌어요!!" 처럼 신나는 말투 | 첫 화면 한 줄만 신나게, 나머지는 부모님이 읽기 편한 차분한 말투 |
| 믿음 장치 | 구독자 수, 실제 날짜·장소를 설명에 정확히 적음 | 날짜·가격·장소를 숫자로 정확히(지어내지 않음), 실제 후기 |
| 연결 | 네이버 카페·인스타·메일 링크 | 블로그·유튜브·카카오톡 버튼 |

정리: 낚낚은 **"밝은 연두 + 두꺼운 글씨 + 사람과 결과물을 크게"**가 핵심이다. 새싹 공방은 PRD에서 고른 **'따뜻한'** 분위기를 바탕으로 깔고, 이 세 가지를 포인트로만 쓴다.

## 2. 색

| 쓰임 | 색 | 메모 |
|---|---|---|
| 바탕 | 크림 `#FFF9EE` | 따뜻한 종이 느낌 |
| 새싹 연두(대표 색) | `#A8D84E` | 낚낚 연두보다 부드럽게 |
| 짙은 초록(글자·테두리) | `#2F4A1E` | 검정 대신 |
| 흙 베이지(카드 배경) | `#F1E3CC` | 화분·흙 느낌 |
| 포인트 다홍(예약 버튼) | `#FF8A5B` | 버튼 하나만 눈에 띄게 |

- 연두는 넓게 칠하지 않고 띠·스티커·밑줄에만 쓴다. 넓게 칠하면 낚낚처럼 너무 세진다.
- 예약 버튼만 다홍색을 써서 "누를 곳은 여기"가 바로 보이게 한다.

## 3. 글꼴 (모두 무료 웹폰트)

- 제목·버튼: **Jua** — 둥글고 귀여운 두꺼운 글씨 (낚낚의 굵은 글씨를 아이 눈높이로 바꾼 것)
- 본문: **Pretendard** — 부모님이 가격·시간을 읽기 편한 글씨
- 큰 제목만 짙은 초록 테두리 + 살짝 기울인 스티커 모양 (썸네일 느낌)

## 4. 귀여운 장치 (과하지 않게 세 가지만)

1. 새싹 두 잎 아이콘 — 로고 옆, 제목 앞 글머리표
2. 둥근 모서리 카드(모서리 크게)와 살짝 기울어진 사진 액자
3. 손글씨 느낌 말풍선 스티커 — 사진 위에 "우리 아이 첫 작품!" 같은 짧은 문구

## 5. 화면 배치 (PRD 6번 순서대로)

1. **첫 화면** — 왼쪽: 큰 한 문장 + [수업 예약 신청] 다홍 버튼 + 작은 [카카오톡 문의]. 오른쪽: 아이 손과 작품 사진 한 장 크게 (낚낚 썸네일처럼 사람+결과물)
2. **한눈에 보기 카드 4개** — 가격 · 몇 살부터 · 날짜·시간 · 위치·주차 (부모님이 궁금한 네 가지)
3. **사진 모음** — 3열 격자, 휴대폰에선 옆으로 넘기기
4. **후기** — 말풍선 카드 (실제 후기만)
5. **블로그·유튜브** — 유튜브 영상 1개 크게 넣기 + 블로그 글 카드 3개
6. **오시는 길** — 지도 링크 + 주차 안내
7. **예약 신청 폼** — 이름 · 연락처 · 희망 날짜 · 개인정보 동의 → [예약 신청하기]
8. 휴대폰에서는 화면 아래에 [예약 신청] · [카톡] 버튼을 늘 떠 있게

## 6. 하지 않을 것

- 낚낚 로고·채널 사진·썸네일을 그대로 쓰기
- 형광색을 화면 전체에 칠하기, 느낌표 남발
- 지어낸 숫자(수강생 수, 만족도 %) 넣기

## 7. 만들기 전에 필요한 것

- PRD 8번 사실(수업 내용·가격·나이·시간·위치·카톡/블로그/유튜브 주소)
- 실제 수업·작품 사진, 실제 후기 문구
