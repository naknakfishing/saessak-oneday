# 사이트 설계도(PRD) — 새싹 공방

작성일: 2026-10-10 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
새싹 공방의 원데이 클래스를 소개하고, 아이와 함께 올 가족의 수업 예약 신청을 받는 사이트.

## 2. 손님
- 누가: 아이와 함께 오는 가족(부모님)
- 어디서 알고 오나: 블로그·네이버 검색

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격
2. 몇 살부터 가능한지
3. 수업 날짜·시간
4. 위치·주차

## 4. 믿게 할 증거 (실제로 있는 것만)
- 수업·작품 사진 (있음 — 파일은 만들 때 받는다)
- 블로그 글 링크 (있음 — 주소는 만들 때 받는다)
- 유튜브 영상 (있음 — 주소는 만들 때 받는다)
- 후기: 실제 후기 있음 (문구는 대표님이 준 그대로만 넣는다. 지어내지 않는다)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 수업 예약 신청
- 누르면: 예약 신청 폼 (결제 없음)
- 보조 연결: 카카오톡 문의 버튼 (예약 버튼보다 작게)

## 6. 페이지 구성 (위에서 아래로, 한 장짜리)
1. 첫 화면 — 한 문장 + [수업 예약 신청] 버튼
2. 수업 소개 — 무엇을 만드는지 · 몇 살부터 · 가격 · 시간 (부모님이 궁금한 네 가지를 한눈에)
3. 수업·작품 사진 모음
4. 후기 (실제 후기만)
5. 블로그·유튜브 — 블로그 글 링크 + 유튜브 영상 넣기
6. 오시는 길 — 위치·주차 안내
7. 예약 신청 폼 + 카카오톡 문의 버튼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 희망 날짜
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
> 아직 받지 못했다. 만들기 전에 대표님께 받아 채운다. 비어 있는 채로 지어내지 않는다.
- 수업 내용(무엇을 만드는지): (미정)
- 가격: (미정)
- 가능 나이: (미정)
- 시간(요일·시각·소요 시간): (미정)
- 위치·주차: (미정)
- 연락 방법: 카카오톡 채널 — 주소 (미정)
- 블로그 주소: (미정)
- 유튜브 주소: (미정)

## 9. 이번에 넣지 않을 것
- 결제 (예약 신청만 받고 결제는 따로 안내)
- 회원가입·로그인
- 사진 올리기(손님이 업로드)
- 알림 메일·문자
- 예약 달력(빈 자리 자동 확인)

## 10. 첫 화면 한 문장 후보
1. 아이와 함께 초록 새싹을 키우는 하루
2. 우리 아이 손으로 만드는 첫 작품, 새싹 공방 원데이 클래스
3. 주말, 아이와 나란히 앉아 만드는 따뜻한 추억

> 수업 내용이 정해지면 문장 속 표현(새싹·작품)을 실제 수업에 맞게 고친다.

## 11. 다음에 할 것
- 회원가입·로그인 (필요해지면 개인정보 처리방침 페이지도 함께)
- 예약 달력·빈 자리 표시
- 예약 접수 알림(메일·카톡)
- 온라인 결제

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 (파스텔 연두·베이지, 포근하고 귀여운 느낌) · 참고 디자인: 유튜브 「낚낚 naknak」 채널 (그대로 베끼지 않고 분위기만) → 세부는 [DESIGN.md](DESIGN.md)
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
0. 8번 '정확해야 하는 사실'과 사진·후기·링크를 대표님께 받는다
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 예약 신청 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
